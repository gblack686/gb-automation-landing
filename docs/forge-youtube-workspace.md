# YouTube Intelligence private workspace

Adds `/atlas/youtube-intel` beside `/atlas/artist-packet-expert`, with an expert
selector in the existing signed-in Studio. Both require `tenant-gbautomation`
membership. This is a read-only website integration, not runtime activation.

`shared/forgeWorkspaces.json` is generated by the monorepo's
`resources/skills/hermes-prospect-agent-team-lead-magnet/scripts/build_youtube_forge.py`.
It supplies exact expert identities and configuration digests to the host and API.
Only the workspace selector may choose an allowlisted binding; caller-supplied
tenant, arbitrary expert, SQL and document keys are rejected. S3 grants are exact
keys. A selected document must match the binding as well as its content hash.

The existing RPC already supports exact expert ownership. No database migration
is needed. Proposal pages, counts and details filter the producer run by both
tenant and selected expert. Missing attribution remains missing. Do not widen the
query to populate an empty screen. YouTube cannot invoke the Artist Packet visual
service; its avatar and configuration come from the existing source registry.

Reports are shared published references in a separate Artifacts section. The
first three slots are sprint, proposals and the existing Bokeh snapshot. The
Bokeh snapshot is general Langfuse telemetry linked from YouTube Intel, explicitly
not YouTube-only activity. Only its pinned immutable Netlify origin is allowed
as a report frame. Report scripts cannot access private workspace memory.

## Verification and release

Run the normal Forge Atlas tests, TypeScript, focused lint, production build and
anonymous browser test. Run `scripts/validate-forge-atlas.mjs` against local Vite
for both values of `FORGE_ATLAS_EXPERT`: `artist-packet-expert` and `youtube-intel`.
Set `FORGE_ATLAS_HTML` to the corresponding generated private document for full
integration testing. Transport is synthetic in that test; it is not live auth.

Land both website and monorepo changes through their normal protected checks.
Then regenerate the document from merged source, confirm the binding digest,
deploy Amplify and upload only `index.html` to the existing private bucket at
`gbautomation/youtube-intel/index.html`. Set SHA-256 metadata and `private,
no-store`. Keep raw profile inputs and receipts out of public website assets.

Production proof must cover authenticated switching, foreign-tenant denial,
unsigned S3 denial, document identity, YouTube-only private reads, verified trace
navigation, report previews and retained Artist Packet behavior. Local tests or
existing Supabase counts do not satisfy that gate. No merge/CI bypass is permitted
under the temporary development fallback.

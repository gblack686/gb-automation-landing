01 Overview 28 words

Date: 2026-06-17 · Owner: Greg Black · Status: draft (v1) Decision: Drop OpenClaw entirely. Jerry → Hermes. Hermes (~/.hermes/) becomes the single agent harness on the Mac Mini; ~/.openclaw/ is decommissioned.

02 1. Summary 116 words

OpenClaw (Jerry, ~/.openclaw/) and Hermes (Gelby, ~/.hermes/) currently run side-by-side on the Mac Mini as user greg. We are retiring OpenClaw: migrate Jerry's functions (4 internal agents + cron fleet + skills) onto Hermes profiles, un-nest all repos and client work out of the ~/.openclaw/workspace/ junk-drawer into the canonical /Users/greg/repos/ (with per-client agent config landing in each client repo's hermes/ dir, per the Carlos precedent), repoint the 69 cron references, then decommission ~/.openclaw/ and reclaim its ~4.7 GB of ephemeral data. Embedded-token git remotes get fixed + rotated along the way.

Thesis: one harness (Hermes), one source-of-truth tree (/Users/greg/repos/), runtime homes that hold runtime only. No agent work buried under a platform-specific path.

03 2. Why now 92 words
  • Hermes is already canonical — Gelby runs on Hermes; the website Hermes-Hub plan commits to per-client Hermes instances; agent-role-map makes Hermes the forward harness. OpenClaw is redundant.
  • The nesting is a liability — ~/.openclaw/workspace/ mixes runtime, logs, artifacts, and redundant clones of client repos (confirmed: ~/.openclaw/workspace/gbauto/<client> are the same gbauto/<client>.git repos already cloned canonically at /Users/greg/repos/<client>). It caused branch-switch friction and is a second source of truth.
  • Two harnesses double the maintenance + secret surface (two auth stacks, two cron systems, two sets of embedded-token remotes).

06 5. Phases 519 words

Phase 0 — Inventory, freeze, snapshot

  • Enumerate Jerry's standing agents, every cron job (id/schedule/prompt/script/paused), skills, and each workspace/* dependency. Freeze the OpenClaw gateway + disarm OpenClaw cron so nothing mutates mid-migration.
  • Snapshot ~/.openclaw/ (config + memory + cron defs; exclude browser/media/backups) to a recovery archive before any deletion. Park any uncommitted work in the nested clones per the git-workspace-cleanup Mini pass.
  • Acceptance: complete agent/cron/skill inventory; freeze confirmed; recovery snapshot exists.

Phase 1 — Path-remap inventory (the 69 references)

  • Produce a table: every ~/.openclaw/workspace/... path referenced by cron/openclaw.json/skills → its /Users/greg/repos/... (or <client>/hermes/) destination. Flag any reference with no canonical destination (real work that only exists nested) for hoisting.
  • Acceptance: every one of the 69 references has a mapped destination or a "hoist" flag; zero unmapped.

Phase 2 — Map Jerry's agents + cron to Hermes

  • Decide the profile mapping (§4 table) and create/extend the Hermes profiles. Translate each OpenClaw cron job to a Hermes cron job (hermes-cron-runner pattern), repointed to canonical paths, paused initially.
  • Acceptance: each Jerry function has a named Hermes home; cron jobs authored (paused), reviewed.

Phase 3 — Migrate per-client config into client repos (<client>/hermes/)

  • For each client (jid5274 already done via carlos-config-to-jid5274; repeat for fisch-group, greg-trading, sylvan-hills, loren-piretra, pbauer, cruz-creations): copy the sanitized agent config from the nested workspace into <client>/hermes/ in the canonical repo, following the Carlos sanitizer rules (never copy .env/auth.json/state DBs; redact tokens). Commit per client.
  • Acceptance: every active client repo has a sanitized hermes/ config tracked; no secrets committed (gitleaks-clean).

Phase 4 — Repoint + cut over cron to Hermes

  • Switch Hermes cron jobs from paused → live (pointing at /Users/greg/repos/*), confirm each fires correctly (receipts), then disable the equivalent OpenClaw cron jobs. Validate with validate-cron-deploy where applicable.
  • Acceptance: every migrated job runs green on Hermes; the OpenClaw cron fleet is fully disabled; no job lost.

Phase 5 — Hoist non-client repos

  • Move ecom_runtime_bundle, hermes-agent, and any other standalone repo out of ~/.openclaw/workspace/ to /Users/greg/repos/ siblings (or confirm a canonical clone already exists and drop the nested one). Update any references.
  • Acceptance: no git repos remain under ~/.openclaw/workspace/.

Phase 6 — Decommission ~/.openclaw/

  • Stop + remove the OpenClaw gateway/launchd jobs; remove ~/.openclaw/ (after the Phase-0 snapshot), reclaiming ~4.7 GB (browser 4.2 GB + media 237 MB + backups 306 MB + logs 180 MB). Remove the Jerry/OpenClaw entries from running services.
  • Acceptance: OpenClaw no longer runs; ~/.openclaw/ removed (or reduced to an empty/archived stub); disk reclaimed; Hermes is the only harness.

Phase 7 — Fix embedded-token remotes + rotate

  • Replace embedded-token remote URLs (both github_pat_ and gho_) with token-less URLs + a git credential helper across all Mini repos. Rotate the leaked tokens (folds into the credential-rotation incident).
  • Acceptance: no .git/config on the Mini contains an inline token; leaked tokens rotated; pushes still work via the helper.

Phase 8 — Update the vault

  • agent-role-map (drop Jerry/OpenClaw, Hermes-only), systems/harnesses/openclaw.md → marked retired, CLAUDE.md stack line, and any skill/doc that references ~/.openclaw/ paths.
  • Acceptance: vault reflects a single Hermes harness; no live doc instructs use of ~/.openclaw/.

02Summarysummary - 270 words

Summary Every diagram and image in a branded report now opens fullscreen on click, on any page built with render_document. Greg asked for this on 2026-07-20, but it only reached pre.mermaid in render_collapsible_report.py. He restated it as "always" on 2026-11-04.

  • Behaviour: click, or Enter/Space when focused, opens it. Esc, the close button or another click closes it, and focus returns to where it was.
  • Left alone: links, buttons, charts with their own expand control, g.clickable nodes, small icons and the logo. data-no-fullscreen opts out one element.
  • Enforced: the CSS and script are pinned house fragments, so a report without them fails report_conformance.

Effects to know about

  • Existing reports get it only when re-rendered, and any older report re-checked against the gate fails until then.
  • Hand-written pages and renderers that don't use render_document don't get it.
  • The old Mermaid handler is removed, so one click can't open two overlays.
  • The fixture diff is large only because the fixtures are regenerated with their own generator.

Test plan GitHub Actions has been frozen org-wide since 2026-10-21, so no CI ran on this PR. Evidence is local, on Windows:

  • Browser: 45 Playwright checks pass on a render_document fixture, including a Mermaid-style class="flowchart" diagram.
  • Browser: both diagrams on a real report open fullscreen with labels and arrowheads intact.
  • validate_report_conformance.py passes on that report.
  • Not run: the full repo test suite, or anything on Linux.

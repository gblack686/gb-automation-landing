test-clients Hermes IaC PRD

Goal

Produce a dry-run quality deployment plan for a dedicated Hermes Telegram agent for client slug test-clients. The plan is intentionally executable later, but this PRD branch does not deploy anything.

Proposed runtime identity:

  • Client slug: test-clients
  • Agent label: test-clients
  • Proposed macOS user: test-clients-agent
  • Runtime home: /Users/test-clients-agent
  • Hermes home: /Users/test-clients-agent/.hermes
  • Hermes workspace: /Users/test-clients-agent/.openclaw/workspace/hermes-agent
  • LaunchAgent label: ai.test-clients.gateway
  • LaunchAgent plist path: /Users/test-clients-agent/Library/LaunchAgents/ai.test-clients.gateway.plist

Non-goals

  • Do not create the macOS user in this dry run.
  • Do not install or load a LaunchAgent in this dry run.
  • Do not write /Users/test-clients-agent/.hermes/.env or any real secret in this dry run.
  • Do not create or update AWS Secrets Manager secrets.
  • Do not touch any other client profile or gateway.
  • Do not start the Hermes gateway.

Success Criteria

  • This branch contains a PRD, rendered config, rendered plist, and Mac-portable deploy and verify scripts.
  • The deploy script defaults to --dry-run=true and prints every action before any real execution.
  • The rendered config.yaml contains no real secrets and keeps CHAT_ID as CHANGEME_TEST_CLIENT_TG_CHAT_ID.
  • All runtime paths are scoped under /Users/test-clients-agent/.
  • Secret inventory names are explicit and use only test-clients scoped resources.

5. Deploy Script

  • Default: --dry-run=true

  9. Install hermes-claude-auth v1.4.0+ into the venv.
  10. Render and lint the plist.
  11. Install cron.
  12. Run scripts/verify-test-clients.sh.

Rollback Procedure

This dry-run branch has no runtime rollback because it does not deploy. For an approved future deploy, rollback is:

sudo -u test-clients-agent launchctl unload /Users/test-clients-agent/Library/LaunchAgents/ai.test-clients.gateway.plist

sudo -u test-clients-agent crontab -l | grep -v 'refresh_hermes_context.sh --client test-clients' | sudo -u test-clients-agent crontab -


sudo -u test-clients-agent mv /Users/test-clients-agent/Library/LaunchAgents/ai.test-clients.gateway.plist /Users/test-clients-agent/Library/LaunchAgents/ai.test-clients.gateway.plist.disabled


sudo -u test-clients-agent mv /Users/test-clients-agent/.hermes/config.yaml /Users/test-clients-agent/.hermes/config.yaml.rollback

Do not delete OAuth credentials, .env, or logs during rollback unless Greg explicitly approves. Preserve /Users/test-clients-agent/.hermes/logs/ and /Users/test-clients-agent/.hermes/state.db for incident review.

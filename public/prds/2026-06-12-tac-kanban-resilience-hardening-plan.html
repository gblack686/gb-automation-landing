  1. Crash circuit breaker + backoff (dispatcher) — enforce default

    2. max_retries=3 and exponential backoff between respawns; on cap, auto-kanban_block with reason crash_loop + last stderr tail. Reuse: the ecom retry-context ledger shipped this sprint (scripts/ecom_retry_context.py, commit b0938e9d) — port the pattern into the Kanban dispatcher. KPI: Attempts ↓. This single change removes ~8.8k junk runs/week.

  2. Death-note capture (spawn wrapper) — wrap worker spawn so exit code,

    3. signal, and stderr tail land in task_run.error instead of pid N not alive; soft-fail provider 429s (park with rate_limited reason + retry-after) rather than crashing. Pairs with the open Hermes-core 429 card.

  3. Completion-protocol Stop hook (worker) — Stop/SessionEnd hook checks a

    4. kanban_complete/kanban_block call occurred this session; if not, block exit once with a reminder, then auto-kanban_block with protocol_violation + transcript tail. Reuse: claude-code-hooks-mastery stop.py / subagent_stop.py; agent-experts stop.py (TAC inventory, 276 hook components catalogued).

  4. Block-reason contract (PreToolUse validator) — reject kanban_block

    5. calls with empty reason/evidence; mirror reason into the board payload so blocked cards are triageable. Fixes failure class 5. Reuse: agentic-finance-review validator-hook family.

  5. Respawn continuity via context bundles — each attempt appends a compact

    6. bundle (what was tried, what failed, remaining steps); respawned workers resume instead of starting blank (Tactic 2: the agent is brilliant but blind). Reuse: context_bundle_builder.py (agentic-prompt-engineering / building-domain-specific-agents).

  6. Dispatch preflight (PreToolUse on kanban_create_task) — validate

    7. target_url/repo/workspace exists and assignee profile is installed before card creation. Evidence: mis-targeted dispatch inferred a rock markdown filename as target_url; profile-missing dispatches dead-end.

  7. Crash-storm alerting + scorecard KPIs — Telegram alert when a task

    8. exceeds N respawns/hour (the 1,472-respawn card should have paged at ~23:30, not been found in the morning); wire the execution-dossier stoppage metrics into sprint_scorecard_metrics weekly (Agentic KPIs: Attempts ↓, Streak ↑, Presence ↓).

  8. Worker generation-usage emission — emit token usage on worker traces so

    9. iteration budgets and cost caps become enforceable; this is the trace-attribution plan's emission phase, re-prioritized by this data.

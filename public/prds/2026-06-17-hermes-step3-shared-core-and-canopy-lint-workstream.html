02 Design decision — where the shared core lives 90 words

Per the ecom Client-Contained Hermes Runtime Boundary ADR (ecom@879831c): shared Hermes owns framework + profile registry + lease/CDP primitives + cron libs; clients reference/pin them, never copy. Recommendation: a versioned shared skill+lib bundle hermes-runtime-core authored in gbautomation/resources/skills/hermes-runtime-core/, deployed to ~/.hermes/skills/ (shared across all profiles, NOT per-profile), and pinned (CalVer tag) like the engine. Clients get it by pin, same model as the engine + the hermes-gbauto template. (Rejected: putting it in the engine fork — keeps the fork lean for upstream syncs; rejected: per-client copies — the anti-pattern.)

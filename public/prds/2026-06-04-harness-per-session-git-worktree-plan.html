02 Goal 77 words

Give each meaningful coding session (or task) its own git worktree so parallel harnesses do not stomp the same working tree. Reuse the proven resources/lib/cron_worktree.py path (/tmp/gbauto-worktrees/ on Mac Mini; Windows sibling outside OneDrive when possible).

In scope: interactive Claude Code, Codex/Cursor, Hermes → Claude TUI delegate, and documentation for operator ergonomics.

Already done: Linear cron (scripts/cron_linear_agent.py) — one worktree per auto/gba- build; Claude Code subagent trees under .claude/worktrees/agent-.

07 Phases 264 words

Phase 0 — Inventory and path policy (one-time)

  • Document current worktrees: git worktree list on Windows + Mac Mini
  • Prune stale .claude/worktrees/agent-* locked trees (operator approval)
  • Set WORKTREE_ROOT env convention: Mac /tmp/gbauto-worktrees, Win C:/tmp/gbauto-worktrees
  • Add WORKTREE_ROOT override to cron_worktree.py (env var, default /tmp/gbauto-worktrees)

Phase 1 — session_worktree.py + registry

  • Add scripts/session_worktree.py wrapping make_worktree / cleanup_worktree
  • Branch naming: cc-task-<slug>, codex-session-<short-id>, cursor-<slug>
  • Write/read ~/.gbauto/var/session-worktrees.json (or repo-local .gbauto/session-worktrees.json for dev)
  • list shows active trees + age; cleanup --older-than 7d best-effort

Phase 2 — Hermes delegate integration

  • Extend plans/2026-06-04-hermes-claude-code-tui-delegate-plan Phase 1 script with --worktree <branch>
  • On ensure --worktree, call session_worktree.py ensure, set pool cwd to worktree path
  • Merge fields into ~/.hermes/var/claude-delegates.json (cwd, branch, worktree_id)
  • Gelby skill hermes-claude-code-tui: use worktree when issue id or explicit /code --wt

Phase 3 — Claude Code + Codex interactive

  • Document operator flow: session_worktree.py ensure my-feature && cd <path> && claude
  • Optional SessionStart: if GBAUTO_WORKTREE_BRANCH set, verify tree exists, inject one-line cwd into briefing
  • Codex: same env contract in .codex/hooks/session-start.sh postamble
  • Cursor: open folder at worktree path (no automation required in v1)

Phase 4 — Observability + cleanup automation

  • resources/lib/tracing.py: optional worktree_branch / worktree_cwd span attributes from registry lookup
  • Weekly cron or OpenClaw skill: prune worktrees with no commit in 14d and no active registry entry
  • Update vault-manifest.json skip_paths if new worktree roots generate noise in validate-write

Phase 5 — SessionStop pairing (optional)

  • On Stop + significant diff, commit in worktree cwd (see plans/2026-06-04-stop-hook-significant-diff-auto-commit-plan)
  • Optional: session_worktree.py finalize — commit, push branch, open PR link in stop-checklist output

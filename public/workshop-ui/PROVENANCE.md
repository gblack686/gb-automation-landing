# Studio source

Promoted from `gbauto/gbautomation` PR #1213, merge
`fcf2a5be836ab15403626bac3055cf59f9013df0`, directory
`artifacts/nexus-forge-window-preview-2026-09-18/`.

The approved Studio shell, logo watermark, locally bundled Inter/Newsreader fonts,
light/dark palettes and five visual variants are preserved. Expert facts come from
the source snapshot in `source-data.js`; they are not a live runtime inventory.
The server catalog records the source revision and the editable draft defaults.

`connected.js` connects private drafts and the single health recipe through the
same-origin React host. `workshop.js` exposes a narrow presentation adapter. The
connected checks window replaces the design example's fixed readiness score.
Conversation, proposals, tasks and changes remain explicitly labeled examples.
No authentication tokens, credentials or private drafts are shipped in this folder.

Refresh source facts deliberately when the expert config changes; do not infer
runtime health or applied settings from this snapshot. Keep any future UI changes
aligned with the shared design source and document intentional divergence here.

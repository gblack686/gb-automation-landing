02 Goal 49 words

Stand up two new public-but-gated routes via Tailscale Funnel so:

  • Gelby's Hermes TUI is reachable from any device at a clean public URL.
  • The ecom-user OpenClaw gateway can be driven externally for the ECOM-1..6 workstream.

Both ride the tailscale-funnel-expose pattern proven by the jid5274 deployment last week.

04 The Gelby pivot 81 words

GBA-399's apps/hermes-chat-expose/ targets :8080. That backend has been down throughout this session and the 5-day gap — the launchd job (xyz.gbautomation.hermes.plist from hermes-iac) is not loaded. Meanwhile, the live Hermes UI is the --tui SPA at :7681 (ttyd), already in service via the :8443/tui Serve.

Retarget the route to :7681. That unblocks today and matches reference_hermes_dashboard_tailnet_serve's description of the actual SPA. The :8080 idea can be revisited separately if a different web chat surface is wanted.

Steps

  1. Retarget Gelby route: apps/hermes-chat-expose/ — flip BACKEND_PORT from 8080 to 7681, update the Caddyfile + installer + RUNBOOK note (one paragraph). The AWS SM secret already exists from last week.
  2. Create ecom route: new apps/ecom-scanner-expose/ from the jid5274 template, constants for :18789 / Caddy :8403 / Funnel :8443. Create the AWS SM secret from the Windows admin identity (same pattern as jid5274).
  3. Retire the :8443 tailnet-only Serve — its /tui mapping is replaced by the new Gelby Funnel at :443 (no /tui prefix — it's root now). The dead /→:3051 half just goes away. The installer handles the Serve removal.
  4. scp + run each installer on the Mac Mini. Both backends are live, so both will activate (no :8080-style abort).
  5. Verify externally — phone test (as with jid5274).
  6. Commit both apps/*-expose/ updates as separate focused commits.

Risks / open notes

  • :8443 Serve retirement — anyone currently using https://gregs-mac-mini.tail4e0ac6.ts.net:8443/tui would lose that path. The TUI content moves to https://gregs-mac-mini.tail4e0ac6.ts.net (root, no prefix). Low traffic — likely just Greg.
  • *ttyd at :7681 binds :7681** (all interfaces). Already reachable on the Mini's LAN IP. Worth confirming whether to constrain that bind, but not part of this PRD.

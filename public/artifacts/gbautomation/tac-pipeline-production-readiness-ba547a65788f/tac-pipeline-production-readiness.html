The 10 pillars that prevent AI slop

Each pillar is a guardrail we shipped because we hit the failure mode and built the fix into the pipeline. None of these are theoretical.

01

Database-logged skill runs

Every agent execution writes to Supabase: run_id, trace_id, status, input hash, output payload, cost, timing. Nothing happens in the dark.

Audit every AI action weeks later.
02

Agent tracing & telemetry

Every agent call is traced end-to-end via Langfuse: inputs, tool calls, token spend, latency, errors. Replay any decision and see exactly why the AI did what it did.

The single thing vibe-coders skip.
03

Linear-driven dispatch

Work enters through Linear issues, not chat. Every build has an issue number, owner, audit trail, and label-gated routing through the right agent team.

No work happens outside the system.
04

Plan-and-review two-step

Before code, a PRD. Before merge, human approval. The AI proposes; humans approve at two checkpoints. Speed without surrendering oversight.

Velocity with brakes.
05

Proper git hygiene

Every build runs on its own branch. PRs only. No force-pushes, no resets. Files never get lost. Reflog and recovery branches as a safety net.

No file has ever vanished.
06

Silent-failure detection

Agents that claim success while actually failing get caught. We scan output for failure markers even when exit codes are clean. The kind of catch only experience teaches you.

Exit code zero doesn't fool us.
07

Idempotent & dedup-safe

The system won't redo shipped work, won't double-pick an issue, won't stomp on in-flight branches. Open PR exists? Skip. Merged PR exists? Skip. Run it 96 times a day, it stays sane.

Safe to run every 15 minutes.
08

Live-credential OAuth

Cron pulls auth from AWS Secrets Manager every run. No stale keys, no "it stopped working overnight", no API keys leaking into client code or test fixtures.

No 3am auth-expired pages.
09

Brand & quality gates

Every visual artifact passes through canonical brand-token validation. Outputs match the live site's exact fonts and colors. Sources are cross-checked. No fabricated proof claims, no off-spec slop.

Output ready for prospects.
10

Async parallel dispatch

Up to 96 build cycles per day, fully parallel via Linear's queue and git worktrees. Engineering velocity without engineering headcount.

What This Says About The Pipeline

2 of 5 samples hard-failed pre-dispatch. Both failures share the same root cause: the work is high-risk enough for team-runner, but the input is still prompt/plan shaped rather than a complete TAC PRD bundle.

2 of 5 samples are missing explicit team-bundle markers. That is the clearest automation target: issue triage should upgrade high and very-high work into full TAC PRD structure before any build worker sees it.

4 of 5 samples lack a `tac_validate` sidecar. That should become the mandatory bridge between PRD creation and dispatch.

01 Overview 38 words

Generated via tac-coder v1.2 (Phase 0 intake → Phase 1 ground → this plan). Cause: 2026-05-16 Langfuse activity-breakdown showed 0/751 traces in last 24h carry token usage or cost. Companion incident report: second-brain/intelligence/observability/langfuse/2026-05-16-activity-breakdown.md.

02 Context 156 words

resources/cc-otel/bootstrap.js monkey-patches globalThis.fetch inside every Node-based agent invocation that loads it via NODE_OPTIONS=--require=…/bootstrap.js. This includes interactive claude-code on Windows + Mac, the Linear cron coding agent on the mini, and any Hermes/OpenClaw call that shells out to a claude subprocess. One bootstrap, many producers.

The hook currently captures HTTP-level facts (http.url, http.method, http.route, http.status_code, http.duration_ms, llm.request.model, llm.input.preview, plus cc.repo, cc.branch, cc.cwd) and ends the span the instant response headers arrive. It never reads the response body. Anthropic's /v1/messages response always carries a usage block (input_tokens, output_tokens, cache_creation_input_tokens, cache_read_input_tokens) plus a stop_reason. None of it lands in Langfuse.

This phase teaches the hook to read the response body for non-streaming requests, extract the usage block + stop reason + response headers + first 500 chars of output text, and emit them as OTel attributes that Langfuse Cloud auto-derives cost from.

03 Scope 318 words

In scope (one PR, one rollout cycle)

  1. Token usage — input_tokens / output_tokens from response body
  2. Prompt-cache tokens — cache_creation_input_tokens / cache_read_input_tokens from response body
  3. stop_reason — from response body
  4. Output preview — first 500 chars of first text block, no redaction (per intake Q3)
  5. Rate-limit headers — anthropic-ratelimit-{requests,tokens}-{limit,remaining,reset} from response headers
  6. Trace session linking — CLAUDE_SESSION_ID env or process-uuid fallback → Langfuse session_id
  7. Invocation source — source:tty | piped | cron tag derived at bootstrap start
  8. Streaming fail-loud — detect SSE responses and emit gen_ai.usage.captured=false reason=streaming instead of silent zero
  9. Smoke test — resources/cc-otel/scripts/smoke-token-capture.sh runs claude -p + waits + reads back from Langfuse via existing langfuse_activity_breakdown.py and asserts Sum output tokens > 0 from the last hour
  10. Unit test — resources/cc-otel/bootstrap.test.js with stubbed fetch covering: non-streaming JSON response with usage, streaming response (fail-loud branch), non-Anthropic URL (untouched passthrough), and the source/session tag wiring

Out of scope (explicit non-goals)

  • Streaming response body parsing — deferred. SSE wrap is its own ~40 LOC; we land the non-streaming win first, validate against Anthropic billing for a known day, then do streaming as a follow-up (see "Follow-up phase" below).
  • Tool-use child spans — assistant tool_use blocks are not parsed into separate observations in this phase.
  • LLM-as-judge scores push — separate cron, separate skill; tracked in second-brain/tasks/feedback-loops/L18-nightly-langfuse-dream-review.md.
  • File-extension / per-file token attribution — requires tool_use parsing first.
  • Tier-3-only trace-linking deeper than session_id — no parent/child span linking across separate claude-code invocations.
  • Hermes / OpenClaw direct SDK paths — covered automatically when they shell out to claude; not covered when they call Anthropic SDK directly. A separate Hermes-side wrapper phase handles those.

Boundary contract

This phase touches only resources/cc-otel/. No edits to Hermes, OpenClaw, Langfuse, the Linear cron, or any plist. After deploy, the existing 514 mac-mini claude-code traces and the existing 29 Hermes-via-subprocess traces start carrying usage; everything else is unchanged.

07 Phase 3 — Build (implementation notes) 444 words
  1. Module-load-time additions (above the existing globalThis.fetch patch):
   const { randomUUID } = require('crypto');
   const _sessionId = process.env.CLAUDE_SESSION_ID || randomUUID();
   const _invocationSource = (
     process.env.CRON || process.env.GITHUB_ACTIONS || process.env.CLAUDE_CODE_NONINTERACTIVE
       ? 'cron'
       : (process.stdin && process.stdin.isTTY ? 'tty' : 'piped')
   );
  1. Inside patchedFetch, replace the current post-response block (currently 4 lines: status, duration, end, return) with a branched read:
   const res = await originalFetch.apply(this, arguments);
   span.setAttribute('http.status_code', res.status);
   span.setAttribute('http.duration_ms', Date.now() - t0);

   // Rate-limit headers — always captured, no body read needed
   for (const h of [
     'anthropic-ratelimit-requests-limit',
     'anthropic-ratelimit-requests-remaining',
     'anthropic-ratelimit-tokens-limit',
     'anthropic-ratelimit-tokens-remaining',
     'anthropic-ratelimit-tokens-reset',
   ]) {
     const v = res.headers.get(h);
     if (v !== null) {
       span.setAttribute('http.response.header.' + h.replace(/-/g, '_'), v);
     }
   }

   // Body read — non-streaming only
   const ct = res.headers.get('content-type') || '';
   if (ct.includes('text/event-stream')) {
     span.setAttribute('gen_ai.usage.captured', false);
     span.setAttribute('gen_ai.usage.capture_skip_reason', 'streaming');
   } else if (ct.includes('application/json') && res.status === 200) {
     try {
       const body = await res.clone().json();
       const u = body.usage || {};
       if (typeof u.input_tokens === 'number') {
         span.setAttribute('gen_ai.usage.input_tokens', u.input_tokens);
       }
       if (typeof u.output_tokens === 'number') {
         span.setAttribute('gen_ai.usage.output_tokens', u.output_tokens);
       }
       if (typeof u.cache_creation_input_tokens === 'number') {
         span.setAttribute('gen_ai.usage.cache_creation_input_tokens', u.cache_creation_input_tokens);
       }
       if (typeof u.cache_read_input_tokens === 'number') {
         span.setAttribute('gen_ai.usage.cache_read_input_tokens', u.cache_read_input_tokens);
       }
       if (body.stop_reason) {
         span.setAttribute('gen_ai.response.stop_reason', body.stop_reason);
       }
       // Langfuse cost-derivation pair — emitted only when we have model + tokens
       if (model && typeof u.input_tokens === 'number') {
         span.setAttribute('langfuse.observation.model.name', model);
         span.setAttribute('langfuse.observation.usage_details', JSON.stringify({
           input: u.input_tokens || 0,
           output: u.output_tokens || 0,
           cache_creation: u.cache_creation_input_tokens || 0,
           cache_read: u.cache_read_input_tokens || 0,
         }));
       }
       // Output text preview — first text block, 500 chars
       if (Array.isArray(body.content)) {
         const txt = body.content.find((c) => c && c.type === 'text');
         if (txt && typeof txt.text === 'string') {
           span.setAttribute('llm.output.preview', txt.text.slice(0, 500));
         }
       }
       span.setAttribute('gen_ai.usage.captured', true);
     } catch (e) {
       span.setAttribute('gen_ai.usage.captured', false);
       span.setAttribute('gen_ai.usage.capture_skip_reason', 'parse_error');
     }
   }

   span.end();
   return res;
  1. Tag list amendments — extend the tags array assembly to push source:${_invocationSource} and set span.setAttribute('langfuse.trace.session_id', _sessionId).
  1. Implementation-time guardrails:
  • res.clone() is essential — calling res.json() on the original would consume the body and break the downstream consumer (claude-code's cli.js bundle).
  • JSON parse is wrapped in try/catch — any non-Anthropic-shaped body (error response, unexpected content) falls through to the fail-loud branch.
  • Streaming detection uses content-type: text/event-stream from response headers (Anthropic's confirmed SSE marker), not request body inspection (which would race with body serialization timing).
  • The gen_ai.usage.captured attribute is set in both branches so a span without it indicates an unhandled code path — easier to spot regressions.

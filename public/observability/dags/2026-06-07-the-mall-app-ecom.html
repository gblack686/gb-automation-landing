03Eagle Trace Format Used185 words

The preferred trace format found in sm-eagle-scaffold is a compact summary plus ordered spans.

Summary fields:

FieldWhy it matters
trace_idStable identifier for the build run or report run
session_idGroups all work for one user or agent session
tenant_id and user_idKeeps client/user context visible
duration_msShows how long the run took
total_input_tokens and total_output_tokensShows model usage
total_cost_usdShows cost when pricing is available
tools_calledLists tools in first-use order
agents_delegatedLists specialist agents in first-use order
span_countShows depth of observable work
statussuccess, error, partial, blocked, or pending
tags and metadataMake filtering and Graphify/report linkage possible
langfuse_urlOpens the source trace when available

Span fields:

FieldWhy it matters
nameagent.<name>, tool.<name>, gate.<name>, or artifact.<name>
span_typeagent, tool, gate, artifact, generation, or event
duration_msTime spent in that node
input_dataWhat the node received
output_dataHuman-readable result preview
parent_idDAG edge back to the calling node
metadata.ownerPerson or agent responsible
metadata.statusNode result
metadata.evidenceFile, report, PR, receipt, or trace link

# GBAutomation public assets

Public, read-only GB Automation asset references for agents.

## Endpoints

- JSON: `/tac/assets.json`
- Style JSON: `/tac/style.json`

## Recommended assets

- `/gb-logo.png` — brand_identity, raster, 302668 bytes, sha256 `ccc593ef48d9...`
- `/gb-signature.png` — brand_identity, raster, 302668 bytes, sha256 `ccc593ef48d9...`
- `/portfolio/samples/logo-motion/poster.png` — portfolio_reference, raster, 1568492 bytes, sha256 `d840efa02797...`

## Non-brand assets observed

- `/vite.svg` exists as a scaffold/sample SVG. Do not use it as a GB brand asset.

## Rules

- Use `/gb-logo.png` or `/gb-signature.png` for GB Automation identity.
- Do not promote client-specific assets through this public style guide.
- Generated SVGs should use cream `#F3F1E7`, ink `#191919`, terracotta `#D97757`, and stone `#D6D4C8`.
